Conversies en basisfuncties

Kopieer dit bovenaan elk script (pure Python 3.8+, werkt standaard op Ubuntu)

import json, re, base64, hashlib
from math import gcd, isqrt, prod

l2b = lambda m: m.to_bytes((m.bit_length()+7)//8, "big") if m > 0 else b"\x00"   # int -> bytes (long_to_bytes)
b2l = lambda b: int.from_bytes(b, "big")                                        # bytes -> int (bytes_to_long)
inv = lambda a, m: pow(a, -1, m)                                                # modulaire inverse (Python 3.8+)

def hex2b(h: str) -> bytes:
    """Hex string (met of zonder '0x', ook bij oneven lengte) -> bytes"""
    h = h.removeprefix("0x").strip()
    if len(h) % 2: h = "0" + h
    return bytes.fromhex(h)

def xor_bytes(a: bytes, b: bytes) -> bytes:
    """XOR twee byte-strings"""
    return bytes(x ^ y for x, y in zip(a, b))

def iroot(x, k):                  # integer k-de wortel, floor; check: iroot(x,k)**k == x
    if x < 2: return x
    lo, hi = 0, 2**(x.bit_length()//k + 1)
    while lo < hi:
        mid = (lo+hi)//2
        if mid**k < x: lo = mid+1
        else: hi = mid
    return lo if lo**k == x else lo-1

def egcd(a, b):                   # (g, x, y) met a*x + b*y = g
    if b == 0: return a, 1, 0
    g, x, y = egcd(b, a % b)
    return g, y, x - (a//b)*y

def crt(cs, ns):                  # x = ci mod ni, ni onderling copriem
    N = 1
    for n in ns: N *= n
    return sum(c*(N//n)*inv(N//n, n) for c, n in zip(cs, ns)) % N

RSA

Basis van RSA

n = p · q, φ(n) = (p − 1)(q − 1), e · d ≡ 1 (mod φ(n)). Encrypt: c = pow(m, e, n), decrypt: m = pow(c, d, n). Met p en q: d = pow(e, -1, (p-1)*(q-1)). Handtekening: s = pow(h, d, n), controle: pow(s, e, n) == h.

Blokken: m moet altijd kleiner zijn dan n, dus lange tekst gaat in blokken van minder dan bitlengte(n)/8 bytes.

Kernidee voor de toets: Elke RSA-aanval doet één van drie dingen: (1) de mod n omzeilen, (2) n factoriseren om φ(n) te vinden, of (3) d of m algebraïsch afleiden zonder te factoriseren.

1. Kleine e, kleine m (geen padding) — Oefening: The group chat

Herken: e=3, c is veel korter dan n, of meerdere gelijke ciphertexten.

Waarom het werkt: De modulo-operatie mod n schudt het getal pas door elkaar als me ≥ n. Als een korte flag zonder padding wordt versleuteld met e = 3, is m3 < n. Dan is c = m3 gewoon een exacte derde macht over de gehele getallen. Als hetzelfde bericht naar meerdere ontvangers wordt gestuurd, zijn alle cijferteksten c1, c2, c3 identiek omdat er nooit gereduceerd is.

Twist op de toets: Als me net iets groter is dan n, geldt c = me − k · n voor een klein geheel getal k. Test dan c + k · n in een lusje.

# Vul in:
n = ...
e = 3
c = ...

m = iroot(c, e)
if pow(m, e) == c:
    print(l2b(m).decode())
else:
    # Twist: m^e net groter dan n? probeer c + k*n
    for k in range(1, 100000):
        m = iroot(c + k*n, e)
        if pow(m, e) == c + k*n:
            print(f"Gevonden bij k={k}:", l2b(m).decode()); break

2. Håstad broadcast (zelfde m, e ontvangers, verschillende n) — Oefening: The better group chat

Herken: e=3 met drie n en drie c (verschillende waarden). Algemeen: minstens e ciphertexten bij exponent e.

Waarom het werkt: Nu is m3 > ni, dus elke cijfertekst ci ≡ m3 (mod ni) is wel gereduceerd modulo zijn eigen ni. Met de Chinese reststelling (CRT) combineer je de 3 vergelijkingen tot één vergelijking modulo N = n1 · n2 · n3. Omdat m < ni voor elke i, is m3 < n1n2n3 = N. Daardoor verdwijnt de modulo-reductie opnieuw en geldt x = m3 exact over de gehele getallen.

# Vul in (bij e=3 heb je 3 paren nodig, bij e=5 heb je 5 paren nodig):
e = 3
cs = [c1, c2, c3]
ns = [n1, n2, n3]

x = crt(cs, ns)
m = iroot(x, e)
assert m**e == x, "Niet exact! Check of cs en ns kloppen"
print(l2b(m).decode())

3. Common modulus (zelfde n, twee e, zelfde m) — Oefening: Free keys

Herken: één n, e1 en e2 met gcd(e1, e2) = 1 (of klein), twee ciphertexten van hetzelfde bericht.

Waarom het werkt: Je hebt c1 ≡ me1 (mod n) en c2 ≡ me2 (mod n). Met het uitgebreide Euclidische algoritme (Bézout) vind je gehele getallen a en b zodat a · e1 + b · e2 = g = gcd(e1, e2). Dan geldt: c1a · c2b ≡ ma·e1 + b·e2 ≡ mg (mod n). Als g = 1 krijg je direct m. Omdat één van beide (a of b) negatief is, neem je eerst de modulaire inverse: c2b ≡ (c2−1)−b (mod n). Is g > 1 (bv. g = 3), neem dan nog iroot(..., g).

# Vul in (dezelfde n, twee verschillende exponenten e1 en e2, twee ciphertexten c1 en c2):
n = ...
e1, c1 = ..., ...
e2, c2 = ..., ...

g, a, b = egcd(e1, e2)          # a*e1 + b*e2 = g
def pw(c, x): return pow(c, x, n) if x >= 0 else pow(inv(c, n), -x, n)
res = pw(c1, a) * pw(c2, b) % n

if g == 1:
    print(l2b(res).decode())
else:
    m = iroot(res, g); assert pow(m, g) == res; print(l2b(m).decode())

4. Wiener (kleine d, e heel groot) — Oefening: Sports car desire

Herken: e bijna zo groot als n (hint over "snelle decryptie"). Werkt voor d < n^(1/4)/3. Variant: Boneh-Durfee tot d < n^0.292.

Waarom het werkt: Uit e · d = 1 + k · φ(n) volgt e/φ(n) − k/d = 1/(d · φ(n)). Omdat φ(n) ≈ n, ligt k/d extreem dicht bij e/n en is k/d altijd een convergent van de kettingbreuk van e/n. Voor elke kandidaat (k, d) bereken je φ = (ed − 1)/k en controleer je of x2 − (n − φ + 1)x + n = 0 gehele wortels p, q heeft (discriminant is een perfect kwadraat).

# Vul in:
n = ...
e = ...
c = ...

def cf(a, b):
    q = []
    while b: q.append(a//b); a, b = b, a % b
    return q

def convs(q):
    h0, h1, k0, k1 = 0, 1, 1, 0
    for a in q:
        h0, h1 = h1, a*h1+h0; k0, k1 = k1, a*k1+k0
        yield h1, k1

for k, d in convs(cf(e, n)):
    if k == 0 or (e*d-1) % k: continue
    phi = (e*d-1)//k; s = n-phi+1; disc = s*s-4*n
    if disc >= 0 and isqrt(disc)**2 == disc:
        print("d =", d)
        print(l2b(pow(c, d, n)).decode())
        break

def rho(n, c=1):                      # Pollard rho
    x = y = 2; d = 1
    while d == 1:
        x = (x*x+c) % n; y = (y*y+c) % n; y = (y*y+c) % n
        d = gcd(abs(x-y), n)
    return d if d != n else rho(n, c+1)

def fermat(n):                        # p en q dicht bij elkaar
    a = isqrt(n)+1
    while True:
        b2 = a*a-n; b = isqrt(b2)
        if b*b == b2: return a-b, a+b
        a += 1

def pm1(n, B=10**6):                  # Pollard p-1
    a = 2
    for j in range(2, B):
        a = pow(a, j, n); d = gcd(a-1, n)
        if 1 < d < n: return d

6. Overige RSA-zwaktes

  • Gedeelde priemfactor: p = gcd(n1, n2), dan q = n // p voor beide sleutels. Bij veel n: gcd over alle paren.
  • Bekende φ(n) of d: p + q = n - φ + 1, los x2 − (p + q)x + n = 0 op. Bekende d en e geeft k = e · d − 1, een veelvoud van φ (kans om n te factoriseren).
  • Zelfde e bij twee c van m en m+a (Franklin-Reiter): bekende lineaire relatie m2 = a · m1 + b (mod n), gcd van polynomen (zie code hieronder voor e = 3 in pure Python, of in Sage).
  • Deel van m of p bekend: Coppersmith in Sage (small_roots) of RsaCtfTool (--attack partial_q).
  • Chosen ciphertext / malleabiliteit / blinding: c' = c * pow(2, e, n) % n decrypt naar 2m. Algemeen: stuur c' = c * pow(r, e, n) % n naar een decrypt-oracle, krijg m' = m · r mod n terug, en bereken m = m' * inv(r, n) % n.
  • Handtekeningen: textbook RSA is multiplicatief, s(m1) · s(m2) = s(m1 · m2). Zonder padding en hash is vervalsen triviaal. Kleine e = 3 met slechte padding: Bleichenbacher e=3.
  • Bekende of kleine plaintextruimte: brute-force alle kandidaten m en vergelijk pow(m, e, n) == c.
  • Timing/fouten (CRT-RSA fault): een fout in één helft geeft gcd(pow(s_fout, e, n) - m, n) = p.
  • p of q nul/negatief/zelfde: controleer of n een kwadraat is (isqrt(n)**2 == n), dan is p = q en φ = p(p − 1).
# Franklin-Reiter voor e=3 met m2 = a*m1 + b (mod n) in pure Python (geen Sage nodig)
def poly_mod(p, m, n):
    p = list(p)
    while len(p) >= len(m):
        if p[-1] != 0:
            fac = p[-1] * inv(m[-1], n) % n
            sh = len(p) - len(m)
            for i in range(len(m)):
                p[sh + i] = (p[sh + i] - fac * m[i]) % n
        p.pop()
    while p and p[-1] == 0: p.pop()
    return p

def franklin_reiter_e3(c1, c2, n, a, b):
    f1 = [(-c1) % n, 0, 0, 1]
    f2 = [(b**3 - c2) % n, (3 * a * b**2) % n, (3 * a**2 * b) % n, (a**3) % n]
    while f2:
        f1, f2 = f2, poly_mod(f1, f2, n)
    m1 = (-f1[0] * inv(f1[1], n)) % n
    return l2b(m1)

A. Korte flag met bekend prefix (cns{) — stereotyped message. Je weet dat m begint met cns{ en een vaste lengte L heeft, dus m = prefix · 256k + x met x het onbekende staartje. Als dat staartje klein genoeg is (enkele bytes), brute-force je x gewoon en vergelijk je pow(m, e, n) == c. Is het staartje te groot voor brute-force maar nog steeds < n1/e, dan is dit een Coppersmith-geval (Sage small_roots); hieronder staat de pure-Python brute-force die op de toets meestal volstaat voor een staart van 2–3 bytes.

# Bekend: prefix-bytes en de totale lengte L van m; alleen een kort stuk is onbekend.
n = ...
e = ...
c = ...
prefix = b"cns{"            # wat je zeker weet aan het begin
L = 11                      # totale lengte van m in bytes (bv. cns{....} = 11)
unknown = L - len(prefix) - 1   # aantal onbekende bytes (de '}' staat vast aan het eind)

base = b2l(prefix + b"\x00"*(L-len(prefix)))   # prefix op zijn plek, rest 0
for x in range(256**unknown):
    m = base + (x << 8) + ord("}")            # vul het midden in, '}' als laatste byte

def dsa_counter_k(p, q, g, y, m1, r1, s1, m2, r2, s2, delta=1):
    h1 = int(hashlib.sha256(m1.encode()).hexdigest(), 16) % q
    h2 = int(hashlib.sha256(m2.encode()).hexdigest(), 16) % q
    num = (s1 * s2 * delta + s2 * h1 - s1 * h2) % q

    x = (num * inv(den, q)) % q
    assert pow(g, x, p) == y
    return x

def elgamal_sig_reuse_k(p, g, y, h1, r, s1, h2, s2):
    mod = p - 1
    diff_s, diff_h = (s1 - s2) % mod, (h1 - h2) % mod
    d = gcd(diff_s, mod)
    assert diff_h % d == 0
    m_red = mod // d
    k0 = ((diff_h // d) * inv(diff_s // d, m_red)) % m_red
    k_found = next(k0 + i * m_red for i in range(d) if pow(g, k0 + i * m_red, p) == r)

    rhs = (h1 - s1 * k_found) % mod
    d2 = gcd(r, mod)
    m_red2 = mod // d2
    x0 = ((rhs // d2) * inv(r // d2, m_red2)) % m_red2
    return next(x0 + j * m_red2 for j in range(d2) if pow(g, x0 + j * m_red2, p) == y)

Key distribution

Diffie-Hellman

A kiest a, stuurt A = ga; B kiest b, stuurt B = gb. Gedeelde sleutel: K = pow(B, a, p) = pow(A, b, p). Aanval op bekende publieke waarden is een discrete log (zie ElGamal). Afleiden: key = sha256(str(K).encode()).digest() (kijk wat de opgave doet, soms sha256(l2b(K)).digest()).

  • Man-in-the-middle: Mallory wisselt met A en B elk een eigen sleutel uit, want DH is niet geauthenticeerd. Oplossing: handtekeningen of certificaten.
  • Kleine subgroep: een aanvaller stuurt een element van kleine orde (bv. B = 1 of B = p − 1), K ligt in een kleine verzameling, brute-force.
  • Kleine exponent of kleine p: BSGS of Pohlig-Hellman (sympy.discrete_log(p, A, g)) voor a of b, dan K berekenen.

Needham-Schroeder (symmetrisch & asymmetrisch)

1. A -> S : A, B, Na
2. S -> A : {Na, B, Kab, {Kab, A}Kb}Ka
3. A -> B : {Kab, A}Kb
4. B -> A : {Nb}Kab
5. A -> B : {Nb-1}Kab

Zwakte (Denning-Sacco): bericht 3 heeft geen tijdstempel, dus een aanvaller met een gecompromitteerde oude Kab kan het opnieuw afspelen (replay). Nonces Na en Nb voorkomen replay van bericht 2 en 4.

Asymmetrische versie (Lowe): 1. A->B: {Na, A}PKb, 2. B->A: {Na, Nb}PKa, 3. A->B: {Nb}PKb. Gevoelig voor man-in-the-middle-aanval doordat B's naam in bericht 2 ontbreekt; verholpen door B's identiteit in bericht 2 op te nemen: {Na, Nb, B}PKa.

Kerberos

  • Client stuurt naam naar AS, krijgt TGT en sessiesleutel, versleuteld met sleutel afgeleid van het wachtwoord.
  • Met de TGT vraagt de client bij de TGS een service-ticket aan, plus authenticator (naam en tijdstempel) versleuteld met de sessiesleutel.
  • Client toont het service-ticket en een nieuwe authenticator aan de service. Tijdstempels beperken replay, klokken moeten dus ongeveer gelijk lopen.
  • Zwaktes: wachtwoordraden op het AS-antwoord, afhankelijk van KDC (Single Point of Failure), kloksynchronisatie.

Sleutelverdeling in het algemeen

  • Hybride: RSA of DH versleutelt een symmetrische sessiesleutel (bv. AES).
  • PKI/X.509: een CA tekent de binding tussen identiteit en publieke sleutel. Controleer keten, geldigheid en intrekking (CRL, OCSP).
  • Public key distribution: publieke aankondiging, publiek directory, authority, certificaten (volgorde van sterkte).
  • Forward secrecy: ephemeral DH, een compromis van de lange-termijnsleutel onthult oude sessies niet.
  • Authenticatie: zonder handtekening of MAC kan DH niet vertrouwd worden.

Protocol-aanvallen uitgewerkt (reflection, type-flaw, kleine subgroep)

De protocol-rijen uit de tabel hierboven, met uitleg en schets-code.

A. Reflection-aanval. Bij een challenge-response waarin dezelfde sleutel in beide richtingen wordt gebruikt, laat je de partij haar eigen challenge beantwoorden. A stuurt een nonce N en verwacht E(N) terug als bewijs dat B de sleutel kent. De aanvaller opent een tweede sessie naar A, stuurt A's eigen N als challenge, en A antwoordt netjes met E(N) — precies wat de aanvaller in de eerste sessie moest leveren. Oplossing: richting/identiteit in het bericht opnemen (bv. E(N, "A->B")), of verschillende sleutels per richting.

# Pseudo: twee parallelle sessies tegen hetzelfde slachtoffer A
# Sessie 1 (aanvaller M doet zich voor als B):  A -> M : N
#   M kan E_k(N) niet zelf maken, dus...
# Sessie 2 (M start een nieuwe sessie naar A):  M -> A : N   (A's eigen nonce!)
#   A antwoordt braaf:                          A -> M : E_k(N)
# M gebruikt dat antwoord in sessie 1:          M -> A : E_k(N)   -> A is "overtuigd"
# Fix: neem de rol/richting in het bericht op, of aparte sleutel per richting.

B. Type-flaw-aanval. Als een nonce en een sessiesleutel dezelfde lengte/codering hebben en het protocol ze niet expliciet typeert, kun je op de ene plek een veld invullen dat eigenlijk voor het andere type bedoeld was. De ontvanger interpreteert bijvoorbeeld een stuk dat jij kiest als "de sleutel". Oplossing: elk veld expliciet typeren (lengte-prefix, tag of structuur die type vastlegt).

# Shamir: reconstructie van f(0) uit shares [(x1,y1),...] mod p
def shamir(shares, p):
    s = 0
    for i, (xi, yi) in enumerate(shares):
        num = den = 1
        for j, (xj, _) in enumerate(shares):
            if i != j: num = num*(-xj) % p; den = den*(xi-xj) % p
        s = (s + yi*num*inv(den, p)) % p
    return s

Belangrijk: RsaCtfTool ondersteunt alleen RSA (geen ElGamal, DSA of Diffie-Hellman). Gebruik het als snelle eerste check of wanneer je een standaard RSA-variatie krijgt.

Overige tools en pagina's om vooraf op te slaan

  • CyberChef offline (github.com/gchq/CyberChef/releases): download de zip, pak uit en open het HTML-bestand voor hex, base64, XOR, "Magic", "From Hex", "To Hex", "From Decimal".
  • SageMath: lattices (LLL), Coppersmith, discrete_log, elliptische krommen.
  • yafu / msieve / cado-nfs: factoriseren van middelgrote n.
  • openssl: openssl rsa -pubin -in key.pem -text -noout (toont modulus in hex en exponent decimaal).
  • Pagina's opslaan (Ctrl+S, "Webpagina, volledig"): ctf-wiki.org (crypto/asymmetric/rsa), Boneh "Twenty Years of Attacks on the RSA Cryptosystem", cryptohack.org (RSA, Diffie-Hellman, Digital Signatures), Wikipedia (RSA, Wiener's attack, Coppersmith's attack, Chinese remainder theorem, Fermat's factorization method, Pollard's rho, Pollard's p−1, ElGamal encryption, ElGamal signature scheme, DSA, ECDSA, Diffie–Hellman, Baby-step giant-step, Pohlig–Hellman, Needham–Schroeder, Kerberos, X.509, ASCII-tabel), en je slides.
  • Controleer in het regeldocument wat is toegestaan. Geen AI, zoekmachines of communicatie.
