    Decomposition of violence N¶

    Attack conditions ¶

    When the bit of N is less than 512, p and q can be obtained using the strategy of large integer decomposition.

    Jarvis OJ - Easy RSA¶

    Here we introduce "JarvisOJ - Easy RSA" as an example, as follows:

    Do you remember veryeasy RSA? Is it not difficult? Let’s take a look at this topic, it’s not hard.
    A known RSA encrypted message is: 0xdc2eeeb2782c and the public key used for encryption is known:
    N = 322831561921859 e = 23
    Please declassify the plaintext, please convert the number to the ascii code commit when submitting
    For example, if the explicit text you solve is 0x6162, then please submit the string ab
    Submission format:PCTF{明文字符串}

    It can be seen that our N is relatively small, where we use factordb directly to decompose, you can get

    3228315619211859=13574881×23781539322831561921859=13574881×23781539

    Let's simply write the following procedure.

    import gmpy2
p = 13574881
q = 23781539
n = p * q
e = 23
c = 0xdc2eeeb2782c
phin = (p - 1) * (q - 1)
d = gmpy2.invert(e, phin)
p = gmpy2.powmod(c, d, n)
tmp = hex(p)
print tmp, tmp[2:].decode('hex')

    The results are as follows

    When p and q are selected in RSA, we can also attack.

    |p-q| is big. ¶

    When p-q is large, there must be a certain parameter that is small, here we assume p, then we can try to divide the modulus by exhausting methods, so as to break the modulus and get the confidential parameters and plaintext information. Basically, not very feasible.

      def mlucas(v, a, n):
    """ Helper function for williams_pp1().  Multiplies along a Lucas sequence modulo n. """
    v1, v2 = v, (v**2 - 2) % n
    for bit in bin(a)[3:]: v1, v2 = ((v1**2 - 2) % n, (v1*v2 - v) % n) if bit == "0" else ((v1*v2 - v) % n, (v2**2 - 2) % n)
    return v1

for v in count(1):
    for p in primegen():
        e = ilog(isqrt(n), p)
        if e == 0: break
        for _ in xrange(e): v = mlucas(v, p, n)
        g = gcd(v-2, n)
        if 1 < g < n: return g # g|n
        if g == n: break

    Common Model Attack ¶

    Attack conditions ¶

    When two users use the same modulus N, different private keys, a common-mode attack occurs when encrypting the same plaintext message.

    Attack principle ¶

    The public keys of the two users are e1e1 and e2e2And the two are mutually important. The plain message is MmThe ciphertext is:

    c1=Me1ModNc2=Me2ModNc1=me1modNc2=me2modN

    When the attacker intercepts c1c1 and c2c2 After that, the plain text can be restored. Use the extension Euclidean algorithm to find out Re1+Se2=1ModNre1+se2=1modn The two whole numbers. Rr and SsFrom this it can be obtained:

    cR1cS2≡MRe1MSe2ModN≡M(Re1+Se2)ModN≡MModNc1rc2s≡mre1mse2modn≡m(re1+se2)modn≡mmodn
