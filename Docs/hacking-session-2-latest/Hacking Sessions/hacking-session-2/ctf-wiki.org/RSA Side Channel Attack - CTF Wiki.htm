    RSA Side Channel Attack ¶

    the Warning

    The current page still doesn't have a translation for this language.

    You can read it through Google Translate.

    In addition, you can also help to translate it: Contributing.

    Energy analysis attack (side channel attack) is a password attack method that can obtain secret information from a password device. Unlike other attack methods: This attack exploits the energy-consuming characteristics of the cryptographic device, rather than the mathematical characteristics of the cryptographic algorithm. Energy analysis attacks are non-invasive attacks that can easily purchase the equipment needed to carry out the attack: so this attack poses a serious threat to the security of password devices such as smart cards.

    Energy analysis attacks are a very important part of the security field, and we will only briefly discuss them here.

    Energy analysis attacks are divided into: - Simple Energy Analysis Attack (SPA), that is, intuitive analysis of energy traces, visible to the naked eye. - Differential Energy Analysis Attack (DPA), based on the correlation coefficient between energy trails analysis.

    Attack conditions ¶

    An attacker can obtain side channel information related to decryption, such as energy consumption, computing time, electromagnetic radiation, and so on.

    Analyze ¶

    Since the site only gives one trace of energy, it can be concluded that this is a Simple channel analysis (SPA) attack. So we can get the key d of the RSA decryption process directly by looking at the level of the energy trail. The theoretical basis for RSA attack by SPA comes from the fast power retention algorithms contained in RSA.

    The fast power algorithm is as follows.

    1. b When it is even,abModc=(a2b/ /2)Modcabmodc=(a2b/2)modc. .
    2. b When it is odd,abModc=(a2b/ /2×a)Modcabmodc=(a2b/2×a)modc. .

    The corresponding C code implementation is: 

    int PowerMod(int a, int b, int c)
{
    int ans = 1;
    a = a % c;
    while(b>0) {
        if(b % 2 == 1) // 当b为奇数时会多执行下面的指令
            ans = (ans * a) % c;
        b = b/2;
        a = (a * a) % c;
    }
    return ans;
}

    Since the value of the index is determined by bit during the calculation of the power of the power, and different operations are taken, the value of d can be restored from the energy trace (from the above, the value obtained directly is the inverse order of the binary value of d).

    Attention:

    Sometimes the die-multiplying can also be performed from high to low. Here is the multiplication from low to high mode.

    This can give the following script for restoring d:

    f = open('./data.txt')
data = f.read().split(",")
print('point number:', len(data))

start_point = 225   # 开始分析的点
mid = 50            # 采样点间隔
fence = 228         # 高低电平分界线

bin_array = []

for point_index in range(start_point, len(data), mid):
    if float(data[point_index]) > fence:
        bin_array.append(1)
    else:
        bin_array.append(0)

bin_array2 = []
flag1 = 0

for x in bin_array:

            flag2 = 1
        else:
            flag1 = 1
    else:
        if flag2:
            bin_array2.append(1)
        else:
            bin_array2.append(0)
        flag1 = 0
        flag2 = 0

# d_bin = bin_array2[::-1]
