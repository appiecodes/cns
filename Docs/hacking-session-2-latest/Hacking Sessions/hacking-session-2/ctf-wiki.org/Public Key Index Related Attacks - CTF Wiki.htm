    Small Public Key Index Attack ¶

    Attack conditions ¶

    e is particularly small, e is 3.

    Attack principle ¶

    Suppose the key used by the user e=3e=3. . Considering that the crypto relationship satisfies:

    c≡M3ModNc≡m3modN

    So:

    M3=c+K×NM=3√c+K×Nm3=c+k×Nm=c+k×n3

    Attackers can go from small to large enumeration. KkOpen the root three times until the whole number is opened.

import gmpy2
from Crypto.PublicKey import RSA
from multiprocessing import Pool

with open('./pubkey.pem', 'r') as f:
    key = RSA.importKey(f)
    N = key.n
    e = key.e
with open('flag.enc', 'r') as f:
    cipher = f.read().encode('hex')
    cipher = int(cipher, 16)


def calc(j):
    print j
    a, b = gmpy2.iroot(cipher + j * N, 3)
    if b == 1:
        m = a
        print '{:x}'.format(int(m)).decode('hex')
        pool.terminate()
        exit()


def SmallE():
    inputs = range(0, 130000000)
    pool.map(calc, inputs)
    pool.close()
    pool.join()


if __name__ == '__main__':
    print 'start'

    RSA Derivative Algorithm – Rabin Algorithm ¶

    Attack conditions ¶

    The characteristics of Rabin's algorithm are that e=2e=2. .

    Attack principle ¶

    ciphertext:

    c=M2ModNc=m2modn

    Declassified:

    • Calculated MPmp and Mqmq::
    MP=√cModPMq=√cModqmp=cmodpmq=cmodq
    • Calculate with the extension Euclidean YPyp and Yqyq::
    YP⋅P+Yq⋅q=1yp⋅p+yq⋅q=1
    • Let's break out four plain words:
    a=(YP⋅P⋅Mq+Yq⋅q⋅MP)ModNb=N−ac=(YP⋅P⋅Mq−Yq⋅q⋅MP)ModNd=N−ca=(yp⋅p⋅mq+yq⋅q⋅mp)modnb=n−ac=(yp⋅p⋅mq−yq⋅q⋅mp)modnd=n−c

    Note: If P≡q≡3(Mod4)p≡q≡3(mod4), then

    MP=c14(P+1)ModPMq=c14(q+1)Modqmp=c14(p+1)modpmq=c14(q+1)modq

    In general,P≡q≡3(Mod4)p≡q≡3(mod4) It is satisfied, for the case of unsatisfied, please refer to the corresponding algorithm to solve.
