    Basic principles ¶

    Coppersmith related attacks are closely related to Don Coppersmith, who proposed a polynomial time for finding all small integer roots for modulus polynomials (monovariables, binary variables, and even multiple variables).

    Here we are mainly introduced by univariate, assuming

    • The modulus is N , and N has a factor. b≥Nβ, ,0<β≤1b≥Nβ,0<β≤1
    • The number of polynomial F is δδ

    In this problem, our goal is to find all the roots of polynomials in the sense of Mode N, which is considered complex. The Coppersmith method is based on the Lenstra–Lenstra–Lovász lattice base reduction algorithm (LLL) method.

    • It has the same root as this polynomial. X0x0
    • Smaller coefficients
    • Definition of an integer field

    The polynomial g, because the root of the polynomial is simple (Berlekamp–Zassenhaus) on the integer field, we get the integer root of the original polynomial in the sense of the model.

    So the question is how to convert f to g? Howgrave-Graham has an idea.

    That is to say, we need to find a polynomial g with a "smaller coefficient", which is the following conversion method.

    In the LLL algorithm, there are two points that are very useful.

    • Only the original base vector is made to the integer linear transformation, which allows us to still use the original g when we get g. X0x0 for the root.
    • The modulus of the resulting new base vector is bounded, which allows us to take advantage of the Howgrave-Graham theorem.

    On this basis, we can build a polynomial g.

    Related Message Attack¶

    M1≡f(M2)ModNM1≡f(M2)modN
