Cryptographic attack on the RSA system

Wiener's attack, named after cryptologist Michael J. Wiener, is a type of cryptographic attack against the RSA cryptosystem. The attack uses continued fraction representation to expose the private key d when d is small.

Background on RSA

[edit]
Main article: RSA (algorithm)

The RSA system is a public key cryptosystem, described as follows. Two large primes p,q are chosen and the product N=pq, known as the modulus, is computed. The Euler totient of N is calculated as φ(N)=(p−1)(q−1). An integer e, called the public exponent, is chosen, and an integer d satisfying ed≡1 (mod φ(N)) is found by use of the Euclidean algorithm.

The public key consists of the pair ⟨N,e⟩, while the private key is the integer d. Encryption of a message, encoded as an integer m, is performed by taking c≡me (mod N), while decryption of ciphertext c is performed by taking m≡cd (mod N). The prime factorization of N is also private and may be included in the private key for a more efficient decryption algorithm.

A possible attack on this system involves either directly finding d given N, or factorizing N first and then computing d as before using the Euclidean algorithm. Note that it is possible to factorize N with the knowledge of any one of p,q or φ(N).

Small private key

[edit]

For performance reasons, one might decide to use a small value of d in order to speed up decryption. However, Wiener's attack shows that choosing a small value for d will result in an insecure system in which an attacker can recover all secret information, i.e., break the RSA system. This break is based on Wiener's theorem, which holds for small values of d. Wiener has proved that the attacker may efficiently find d when d<13N1/4.[1]

Wiener's paper also presented some countermeasures against his attack that allow fast decryption. Two techniques are described as follows.

Choosing large public key: Replace e by e′, where e′=e+kφ(N) for some large integer k. When e′ is large enough, for example e′>N3/2, Wiener's attack cannot be applied regardless of how small d is.

Using the Chinese remainder theorem: A more efficient decryption algorithm, known as CRT-RSA, may be performed by using the primes p,q as the moduli during decryption instead of N.

Suppose one chooses d such that both dp≡d (mod p−1) and dq≡d (mod q−1) are small but d itself is not, then a fast decryption of the ciphertext c is performed as follows:

  1. First compute mp=cdp (mod p),mq≡cdq (mod q).
  2. Use the Chinese remainder theorem to compute the unique value of 0≤m<N that satisfies m≡mp (mod p) and m≡mq (mod q). The resulting m satisfies m≡cd (mod N). The point is that Wiener's attack does not apply here because the value of d mod φ(N) can be large.[1]
See also: RSA (algorithm) § Using the Chinese remainder algorithm

How the attack works

[edit]

Since ed≡1 (mod φ(N)), there exists an integer k such that

ed=k(p−1)(q−1)+1.

Dividing by Nd=pqd gives

eN=kd(1−δ), where δ=p+q−1−1kpq is small.

Importantly, the fraction e/N consists of public data and is approximated by the fraction k/d consisting of private data. Wiener's attack exploits this fact by using the continued fraction expansion of e/N to generate fractions close to e/N, known as convergents, and guessing k and d to be the numerator and denominator of these approximating fractions. Note that the continued fraction for a rational number appears as a byproduct of the Euclidean algorithm and may be computed quickly. When the denominator d is small enough relative to N, the fraction k/d is guaranteed to be one of these convergents.

The guess can be checked by using k and d to compute φ(N)=(ed−1)/k and then checking if this guess for φ(N) factorizes N by solving the quadratic equation

x2−(N−φ(N)+1)x+N=0.

Wiener's theorem

[edit]

Let N=pq with q<p<2q, and let d<13N1/4.

Given ⟨N,e⟩ with ed≡1 (mod φ(N)), the attacker can efficiently recover d.[1][2]

Example

[edit]

Suppose that the public keys are ⟨N,e⟩=⟨90581,17993⟩. The attack should determine d. By using Wiener's theorem and continued fractions to approximate d, first we try to find the continued fractions expansion of eN. Note that this algorithm finds fractions in their lowest terms. We know that

eN=1799390581=15+129+⋯+13=[0,5,29,4,1,3,2,4,3]

According to the continued fractions expansion of eN, all convergents kd are

kd=0,15,29146,117589,146735,5552794,12566323,557928086,1799390581.

We can verify that the first convergent does not produce a factorization of N. However, the convergent 15 yields

φ(N)=ed−1k=17993×5−11=89964

Now, if we solve the equation

x2−(N−φ(N)+1)x+N=0
x2−618x+90581=0,

then we find the roots which are x=379; 239. Therefore we have found the factorization

N=90581=379×239=p×q.

Notice that, for the modulus N=90581, Wiener's theorem will work if

d<13N1/4≈5.7828.

Proof of Wiener's theorem

[edit]

The proof is based on approximations using continued fractions.[1]

Since ed≡1 (mod φ(N)) there exists a k such that ed=kφ(N)+1. Therefore

|eφ(N)−kd|=|ed−kφ(N)dφ(N)|=1dφ(N).

Hence, k/d is an approximation of e/φ(N). Although the attacker does not know φ(N), they may use N to approximate it.

To see this, note the hypothesis q<p<2q implies N=pq>q2, and so

N−φ(N)=p+q−1<3q−1<3N.

Also, N−φ(N)>0 for N>1.

The above estimate lets us approximate ed=kφ(N)+1 by kN+1 (relative to k):

|ed−(kN+1)|=|(kφ(N)+1)−(kN+1)|=|k(φ(N)−N)|<3kN.

In fact, because N−φ(N)≥1, we can approximate ed by kN (relative to k):

|ed−kN|=|1−k(N−φ(N))|=k(N−φ(N))−1<k(N−φ(N))<3kN.

Therefore,

|eN−kd|=|ed−kNNd|<3kNNd=3kdN

Now, since e<φ(N),

k=ed−1φ(N)<edφ(N)<d<13N1/4.

Therefore,

|eN−kd|<3kdN<1dN1/4<12d2

where the last inequality uses 2d<N1/4 from the assumption on d.

Now in general, if |x−ab|<12b2, then ab is a convergent of x, so k/d appears among the convergents of e/N. We may guess k and d to be the numerator and denominator of these convergents respectively, and verify if they are correct by computing φ(N) and attempting to factorize N with these guesses. Eventually one such guess (of which there are O(log⁡N) of them [1.1]) will be correct.

Python implementation

[edit]

The following is a minimal implementation of Wiener's attack in Python, given a vulnerable system with public key ⟨N,e⟩, based on an online implementation[3].

import math


# Convergents of num/den as fractions
def convergents(num, den):
    # The Euclidean algorithm gives the denominators, then compute convergents
    ni, di = (0, 1), (1, 0)
    while den != 0:
        div = num // den
        num, den = den, num % den
        ni = (ni[1], div * ni[1] + ni[0])
        di = (di[1], div * di[1] + di[0])
        yield (ni[1], di[1])


# Factorizes N when successful
def wiener(N, e):
    for k_guess, d_guess in convergents(e, N):
        if k_guess == 0:
            continue
        phi_guess = (e * d_guess - 1) // k_guess
        # Solve the quadratic
        coeff = N - phi_guess + 1
        disc = coeff * coeff - 4 * N
        if coeff <= 0 or coeff >= N + 1 or disc < 0:
            continue
        root_disc = math.isqrt(disc)
        if root_disc * root_disc != disc:
            continue
        return ((coeff + root_disc) // 2, (coeff - root_disc) // 2)
    return None
